# ADR-0003 — Foundation runtime and official starter import

Status: proposed for review in Issue #5 and the official-starter PR. This does not approve visual identity, product scope, production serving/deployment, or canonical-data policies.

## Choice and provenance
Import only the official upstream `laravel/react-starter-kit` revision `717b8f55aefd82d25d4119eaebdc8e3a72b8d7e5` into the existing SongChart Next repository. Preserve SongChart-authored README, AGENTS, governance, roadmap, Docker and design authorities; do not copy old SongChart. The upstream kit uses Laravel 13/PHP ^8.3, React 19/Inertia 3/TypeScript, Tailwind/Radix/shadcn primitives and Fortify/passkeys scaffolding. These packages are not a SongChart visual design or activated user-facing product feature.

Development: PHP 8.4, Node 22, pnpm 10.17.1, multi-stage Docker targets and PostgreSQL 18.6. PHP extensions are checked at image build; pdo_pgsql for runtime, pdo_sqlite solely for upstream in-memory scaffold tests, intl/mbstring/zip/opcache for runtime/build support. One authoritative JS lockfile (pnpm-lock.yaml) and composer.lock must be generated by real package resolution, committed, and checked before any app build is accepted.

PostgreSQL 18 changes data volume mount to /var/lib/postgresql. Use a *new* named volume postgres18_data and leave any PostgreSQL 17 volume untouched; upgrades of existing data require separate backup/restore/pg_upgrade planning. Development image tag is not immutable production provenance. Pin digest for controlled releases after verifying the multi-architecture manifest.

## Boundaries
Initial local topology is app+db. No Redis, Nginx, Kestra, Meilisearch, separate worker or production controller is activated. Development uses artisan serve; production Docker target offers php-fpm only and is **not** a deployable web stack until serving, secrets, image provenance, ingress, health, recovery and release gates are approved. No automatic migration of existing volumes or canonical records.

Upstream auth and welcome/dashboard pages are unapproved scaffold, not SongChart product or Design Authority. Remove/restrict via separate scoped review after starter baseline, without promoting UI baselines. OpenAPI single declaring authority is a separate ADR before public API implementation.

## Acceptance
Real lockfiles; matching official upstream source provenance and license review; `docker compose config`, dev image build, php platform requirements, PostgreSQL 18 connectivity, starter tests, type/check/build and governance CI on exact PR SHA. Feature Artist, live ingestion, production restore and deployment remain unimplemented until separately evidenced.
