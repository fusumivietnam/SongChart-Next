# Operations runbooks

Operational runbooks are repository evidence for repeatable environment actions. They do not by themselves prove that an environment is deployed.

- `CI_WORKFLOW_OWNERSHIP.md` — CI workflow ownership and credential boundaries.
- `VS04_RECOVERY_ROLLBACK.md` — disposable PostgreSQL backup/restore and migration rollback evidence.
- `G5_VPS_RUNBOOK.md` — first production VPS execution under ADR-0015.
- `VERCEL_PREVIEW.md` — zero-cost Vercel Hobby + isolated PostgreSQL preview/test execution under ADR-0016; never G5 production evidence.
